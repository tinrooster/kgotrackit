# Help Menu Reference

## Goal

The in-app Help page provides operational guidance for end users and administrators without requiring external docs navigation.

## Section Map

### Quick Navigation

- Dashboard: status and quick checks
- Inventory: item lifecycle and editing workflows
- Check-In/Out: secure cabinet movement operations (`/checkout`)
- Reports: report creation and export workflows
- Settings: configuration and data governance
- About: product profile and build context

### User-defined Items & Settings Behavior

- Explains how changes to shared lists affect existing inventory records
- Covers rename/remove reconciliation behavior
- Recommends backup/export before structural edits

### Inventory Workflow

- Create item/template
- **Quick add** (Inventory toolbar): fast capture with selection strip, collapsible lists, voice/last name, barcode/camera, units with sub-sizes (e.g. Spools), and device-local shortcuts — see in-app Help → Quick add
- Classify and assign location/project
- Use bulk edit for large updates
- Use Check-In/Out for movement operations
- Print labels and run reports

### Reports & Exports

- Built-in and custom report usage
- Filter-first workflow and preview checks
- CSV/XLSX usage guidance

### Logging, Audit, and Security Notes

- Distinguishes audit, system, performance, and security logs
- Documents compact vs detailed System Logs views
- Covers export and durable retention behavior

### Backup & Restore

- Data Management tab usage
- Backup timing recommendations
- Operational rollback hygiene

## Maintenance Guidance

- Keep Help content aligned with actual UI labels and menu structure.
- Update Help whenever workflow behavior or routing changes.
- Keep operational instructions concrete and task-focused.
